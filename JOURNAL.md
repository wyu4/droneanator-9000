## 10/27/2025 - Initialized a PlateformIO project  

[_See code at the time of this journal_](https://github.com/wyu4/droneanator-9000/tree/4b9f5c6134cd28b11458651c09966f8af48db12c)

I previously had experience writing code for Arduino using the Arduino IDE. However, as a VSCode user, I found that the Arduino came short when it came to user-friendliness.

For this project, I decided to use VSCode, since it allows me to install community driven extensions made for thing such as code linting, formatting, and completion.

I didn't know how to do this, so I referred to YouTube videos online, which led me to PlatformIO.

### PlatformIO
PlatformIO is a extended IDE for VSCode, which is a nice alternative to the Arduino IDE. It comes packet with its own UI and toolbar for comipling and uploading code, and supports most Arduino or ESP32 models.

The Droneanator-9000 uses an ESP32-S3-WROOM with the Arduino framework.
![image](https://blueprint.hackclub.com/user-attachments/blobs/proxy/eyJfcmFpbHMiOnsiZGF0YSI6NjEyNCwicHVyIjoiYmxvYl9pZCJ9fQ==--5bd262edb3ce024cc7d4a37b4d6ced5a4d663713/image.png)
And from there, PlatformIO initialized the project for me, with all the minimum libraries that my particular ESP32 is compatible with.

### Starter code
I didn't stop at initializing a PlatformIO project. I also started writing some starter code for the drone.

![image](https://blueprint.hackclub.com/user-attachments/blobs/proxy/eyJfcmFpbHMiOnsiZGF0YSI6NjEyMiwicHVyIjoiYmxvYl9pZCJ9fQ==--d68930e990ad765ebde136dcb360d5b35e3aa506/image.png)

I started with a Telemetry section that handles all things logging (to a Serial monitor, or over a WiFi UDP connection). For now, this section only handles printing strings. The ESP32 will open a WiFi network with the SSID and password specified in Credentials.h (excludded from GitHub for privacy reasons), and can detect when a connected device sends a "heartbeat" packet to the ESP32 (will be used later on by an app that is designed to receive and display telemetry from the Droneanator 9000).

I then went on to write some code for the Electric Speed Controllers (ESC), before reaslizing that I need to know some technical details with the ESCs and how they receive PWM signals before I can really do anything. So I ended up leaving it for later.

Finally, I wrote some code for the receiver, which will receive data from a controller over a radio frequency. The code only entails how the ESP32 will communicate with the receiver over an iBus connection.
